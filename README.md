# GUI Приложение: Currency Converter

Программа с графическим интерфейсом для мгновенной конвертации популярных валют с использованием актуальных рыночных курсов.

## Авторы
Атарщиков Егор

## Как получить API-ключ
1. Перейдите на сайт [exchangerate-api.com](https://exchangerate-api.com).
2. Введите свой email на главной странице для бесплатной регистрации.
3. Подтвердите почтовый ящик и войдите в личный кабинет.
4. Скопируйте ваш персональный **API Key**.
5. Создайте в корне проекта файл `config.json` следующего содержания:
   ```json
   {
     "api_key": "ВАШ_СКОПИРОВАННЫЙ_КЛЮЧ"
   }
   ```

## Тестирование и примеры использования
* **Тест 1 (Успешный):** Выберите `USD`, выберите `EUR`, введите сумму `100`. Нажмите "Конвертировать". В поле вывода отобразится эквивалент в евро, а строка запишется в таблицу истории.
* **Тест 2 (Валидация):** Введите в поле суммы `-50` или `abc`. Приложение выдаст ошибку: *«Ошибка: Введите положительное число!»*.
* **Тест 3 (Одинаковые валюты):** Выберите `USD` в обоих полях. Приложение выдаст предупреждение: *«Выберите разные валюты!»*.
